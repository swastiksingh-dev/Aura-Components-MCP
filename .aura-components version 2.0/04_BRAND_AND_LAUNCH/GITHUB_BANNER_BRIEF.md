# GitHub banner — original Aura 2.0 identity brief

## Objective

Create a fresh banner from scratch. It must feel like a serious open-source design-engineering tool, not a generic AI gradient poster.

## Core visual idea

A clear left-to-right visual journey:

**Brief → Design intelligence → Components → Motion → Responsive verification**

Use a central abstract interface canvas or layered browser panels with precise grid geometry. Show a few UI primitives being organised into a coherent composition; a subtle motion path or animated line can connect the stages. The visual should communicate engineering clarity and creative quality.

## Art direction

- Premium editorial + technical aesthetic.
- Dark ink/charcoal base with carefully limited electric cyan/blue or warm accent; choose one coherent palette.
- Strong typography, grid, sharp spacing and high contrast.
- Clean vector shapes and believable UI fragments.
- Restrained glow only if it improves hierarchy; no clutter, random glass cards or generic AI sparkle motifs.
- Keep important text in a central safe region for GitHub crop variations.

## Text hierarchy

Primary: `AURA COMPONENTS MCP 2.0`

Secondary: `From interface ingredients to intentional experiences.`

Capability line (only after shipped): `Design intelligence · Motion · Responsive QA · Research`

Do not put tiny tool counts or frequently changing catalogue metrics into the banner.

## Production requirements

- Master: 1600 × 900 px (16:9) or larger at the same ratio.
- Export GitHub-ready PNG at a sensible file size.
- Include editable vector/source file (SVG, design source or reproducible code) in `assets/brand/`.
- Check legibility at 50% scale and when cropped to common social-preview sizes.
- Include a monochrome/low-colour variant only if it is genuinely useful.
- No stock/watermarked assets, copied logos, or unlicensed typefaces.

## Generation prompt starter

> Design an original high-end GitHub hero banner for “AURA COMPONENTS MCP 2.0”, an open-source MCP server for AI-assisted web design engineering. Show a precise, editorial interface system evolving from a raw brief into a coherent responsive website: small component tiles align into a clear browser composition, a restrained motion path links the stages, and viewport outlines hint at mobile/tablet/desktop verification. Use sophisticated typography, strong grid logic, controlled negative space, crisp vector-like UI details, a dark ink foundation and a single restrained electric accent. Make it feel authored by a meticulous product design studio. Keep the main title large and perfectly readable. Avoid generic AI imagery, random gradients, clutter, fake dashboard text, fake metrics, 3D blobs and stock-photo aesthetics. Composition must remain legible after crop.

The final asset must be manually inspected and text corrected; generated image text can be inaccurate. If image generation is unavailable, build the banner in SVG/CSS with exact typography and editable elements.
