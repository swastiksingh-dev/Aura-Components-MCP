# Aura Components MCP 2.0 — Agent Execution Package

This folder is the complete planning and execution brief for the next major release of [Aura Components MCP](https://github.com/swastiksingh-dev/Aura-Components-MCP).

## Start with one file

**Give your coding agent this file first:** `00_START_HERE.md`

Extract this ZIP into the Aura repository root so the folder `.aura-components version 2.0/` sits beside `package.json`. Then use `START_AGENT_PROMPT.md` in OpenCode. It instructs the agent to inspect the real repository, create a safe working branch, establish baselines, and begin Session 1. The agent should not load every document into context at once.

## The five sessions

1. Foundation and repository reorganisation.
2. MCP tool contracts, context efficiency and catalogue improvements.
3. Design Intelligence and research library.
4. Motion, responsive design and verification, including optional REA workflow.
5. README, new banner, launch-video production package and release readiness.

## What's included

- Product charter and current baseline.
- Five detailed session runbooks with copyable prompts and acceptance criteria.
- Design Contract and MCP tool contract specifications.
- Context-budget, search, comparison and reference-intelligence plans.
- Motion planning, responsive auditing and browser-verification specifications.
- Research ingestion and curated bibliography.
- Optional REA MCP workflow.
- Repository reorganisation plan and OpenCode multi-agent workflow.
- OpenCode agent instruction files and example permissions configuration.
- README, GitHub banner, launch video and social launch briefs.
- Testing, security, migration and release gates.

## Important

This is an implementation blueprint, not a claim that v2 features already exist. The agent must verify every current repository detail and update stale assumptions. No push, npm publish, tag or public release should happen without explicit approval.
