# Support

Questions, bugs, and ideas live in GitHub Issues:

- Bug: use the **Bug report** template (tool + args, expected vs got,
  `fallback` shown, version).
- Idea: use the **Feature request** template (agent job it unblocks,
  exact tool shape).

Security issues: see [SECURITY.md](./SECURITY.md) — do not open them
as public issues.

Usage help: [SETUP.md](./SETUP.md) first, then
[README.md](./README.md). Catalogue content questions belong to Aura;
server/code questions belong here.
