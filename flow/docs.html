How it works, slowly.

New to MCP? Read top to bottom. Five minutes.

What is this?

A Model Context Protocol server: a program your AI agent launches and talks to over stdio (initialize, tools/list, tools/call). Ours exposes the free Aura catalogue as 15 tools.

The four-step loop

  1. Status: aura_status confirms reachability + counts.
  2. Search: aura_search_all fans out to components, skills, assets, systems in parallel. Lists carry titles, tags, views, page_url — no blobs, so it stays fast.
  3. Fetch: aura_get_* loads the finalist in full (capped at 12k chars).
  4. Install: aura_install_* / aura_use_design_system return steps, file map, CDN scripts, token CSS.

Why free-only?

Every component/asset query filters private=false + premium=false. Pro ids are refused with an explanation instead of leaking paid source. Skills and design systems have no premium tier; public rows are free.

Why so fast?

One 34KB zero-dependency bundle, 60s LRU cache (300 keys), in-flight request coalescing, author memo, jittered retries, bounded payloads.
