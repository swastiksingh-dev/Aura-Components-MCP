What is this?

An MCP server: a program your agent launches over stdio (initialize, tools/list, tools/call). Ours exposes the free Aura catalogue as 20 tools.

Loop

  1. Status (aura_status) → search (aura_search_all) → fetch (aura_get_*) → install (aura_install_*).

Free-only

Queries filter private=false + premium=false. Pro ids are refused with an explanation instead of guessing.

Fast

48KB bundle · 60s LRU (300 keys) · request coalescing · bounded payloads · retries with jittered backoff.

Install via npm

On npm as aura-components-mcp — no repo needed. Global install, then run, or zero-install straight through npx:

npm install -g aura-components-mcp
npx -y aura-components-mcp@latest

Full client matrix lives in Setup.
