why

Why not the official MCP?

Aura ships an official MCP for your projects. This covers the public catalogue — no OAuth, no key.

free-only default

No login, ever

Reads hit public endpoints. Pro rows never sneak in; Pro ids are refused with an explanation.

48KB · 60s cache

Fast by design

One bundled file, zero deps, LRU + coalescing, bounded payloads, retries with backoff.

install

One file. Any client.

git clone https://github.com/swastiksingh-dev/aura-components-mcp.git
cd aura-components-mcp
npm run build
node ./dist/server.js
If it prints listening on stdio, it works. Then register: claude mcp add aura-components -- node ./dist/server.js · or skip the clone via npm i -g aura-components-mcp · full matrix in Setup.
