setup

Three commands.

1 · Get the server — pick your way

git clone https://github.com/swastiksingh-dev/Aura-Components-MCP.git
cd Aura-Components-MCP
npm run build
node ./dist/server.js
npm install -g aura-components-mcp
aura-components-mcp
npx -y aura-components-mcp@latest

If it prints listening on stdio, it works. Ctrl+C, then register. Package: npmjs.com/package/aura-components-mcp

2 · Register — pick your client

claude mcp add aura-components -- node ./dist/server.js
// ~/.cursor/mcp.json — Cursor / Windsurf
{ "mcpServers": { "aura-components": { "command": "node", "args": ["./dist/server.js"] } } }
// opencode.json — OpenCode
{ "mcp": { "aura-components": { "type": "local", "command": ["node", "./dist/server.js"] } } }
// Codex / Cline / Roo — same stdio pair
command: node · args: ["dist/server.js"]

Installed via npm -g? Use command aura-components-mcp with no args. Prefer zero-install? Use command npx, args ["-y", "aura-components-mcp@latest"].

3 · First prompt

Check aura_status. Then recommend a starter kit for a dark cinematic portfolio (free only).
Trouble? npm run verify runs 18 live checks. Zero tools = path not absolute or client needs restart.
