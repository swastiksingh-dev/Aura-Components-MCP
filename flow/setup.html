From git clone to first answer.

Copy each block in order. Nothing to sign up for.

1 · Clone + build

git clone https://github.com/swastiksingh-dev/Aura-Components-MCP.git
cd Aura-Components-MCP
npm run build
node ./dist/server.js

If the last line prints listening on stdio (plus the Aura credit lines), the server works. Press Ctrl+C, then register it below.

2 · Register in your agent

Claude Code: claude mcp add aura-components -- node ./dist/server.js

Cursor / Windsurf (~/.cursor/mcp.json): { "mcpServers": { "aura-components": { "command": "node", "args": ["/abs/path/dist/server.js"] } } }, then restart.

Codex: codex mcp add aura-components -- node ./dist/server.js

OpenCode (opencode.json): { "$schema": "https://opencode.ai/config.json", "mcp": { "aura-components": { "type": "local", "command": ["node", "/abs/path/dist/server.js"], "enabled": true } } }, then restart or run /mcp.

Cline / Roo / DeepSeek Harness: command node, args ["/abs/path/dist/server.js"], transport stdio.

3 · First prompts

Check aura_status. Then recommend a starter kit for a dark cinematic portfolio (free only).

Search free pricing components, get the top two in full, compare them.

Trouble? npm run verify runs 18 live checks. Zero tools in client = path not absolute or client needs restart. Stale counts = 60s cache, wait or set AURA_CACHE_TTL_MS=0.
