setup

Three commands.

1 · Clone + build

git clone https://github.com/swastiksingh-dev/Aura-Components-MCP.git
cd Aura-Components-MCP
npm run build
node ./dist/server.js

If it prints listening on stdio, it works. Ctrl+C, then register:

2 · Register

Claude Code: claude mcp add aura-components -- node ./dist/server.js

OpenCode (opencode.json): { mcp: { aura-components: { type: local, command: [node, dist/server.js] } } }

Cursor / Windsurf: command node, args [dist/server.js]

Codex / Cline / Roo: same stdio pair.

3 · First prompt

Check aura_status. Then recommend a starter kit for a dark cinematic portfolio (free only).

Trouble? npm run verify runs 18 live checks. Zero tools = path not absolute or client needs restart.
