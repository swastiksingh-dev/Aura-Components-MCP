how it works

Search small. Fetch full. Paste clean.

Four steps, one idea: lists stay tiny, details load only for finalists, and the guide turns winners into paste-ready answers.

1 · AI agent

asks in plain words

2 · This MCP

searches 4 tables in parallel

3 · Aura catalogue

returns rows + counts

Then: pick, fetch, paste

  1. aura_search_all shows which surface has the best match.
  2. aura_get_component / aura_get_skill / aura_get_design_system fetch the finalist in full (capped at 12k chars).
  3. aura_install_component / aura_install_skill / aura_use_design_system turn it into steps, files, and tokens.
Beginner rule: status, then search-all, then get-one, then install-one. Never fetch everything up front.
