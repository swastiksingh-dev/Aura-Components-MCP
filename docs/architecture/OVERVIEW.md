# Architecture overview — Aura Components MCP 2.0.0 (release candidate)

Source is authoritative. `dist/` is generated by `npm run build` and must never
be hand-edited.

## Request path

```text
dist/cli.cjs
  └─ require("./server.js")            (generated single-file bundle)
      └─ src/server.mjs                composition root + stdio framing
          ├─ loadConfig()              src/config.mjs (env names/defaults)
          ├─ createFetcher()           src/http.mjs (timeout/retry seam)
          ├─ createCatalog()           src/catalog.mjs (deep module)
          ├─ createIcons()             src/icons.mjs
          ├─ createVersion()           src/version.mjs
          ├─ createAwardClient()       src/awards.mjs
          ├─ createAwardIndex()        src/awards-index.mjs
          ├─ createBrowserAdapter()    src/browser-cdp.mjs (optional)
          └─ createSession()           src/protocol.mjs (JSON-RPC/MCP)
              └─ tools/call → handlers[name] → src/tools.mjs
                   └─ catalog | guide | design-research | motion-plan | icons | version | awards | awards-index | browser-cdp
                      └─ textResult(JSON)  src/protocol.mjs
```

Protocol handling is transport-only: `src/protocol.mjs` validates the envelope,
enforces `initialize` before `tools/list`/`tools/call`, and maps `BAD_ARGS` →
`-32602`, `NOT_FOUND` → `-32004`, everything else → `-32000`.

`src/tools.mjs` is a thin registry: each handler validates arguments at the
seam and delegates to one domain module. Tool schemas (`TOOL_DEFS`) and
handlers live in the same file so registry drift is visible in one place.

## Module responsibilities

| Module | Owns | Does not own |
| --- | --- | --- |
| `src/config.mjs` | Env parsing, defaults, clamping | I/O |
| `src/http.mjs` | Fetch timeout, retry/backoff, error mapping, injectable fetch | Catalogue semantics |
| `src/catalog.mjs` | PostgREST queries, cache/coalescing, shaping, free-only access policy, page URLs, counts | Tool validation, prompt/guide text |
| `src/guide.mjs` | Install plans, prompt/docs helpers, facets, scaffold merge | Network calls |
| `src/tools.mjs` | Tool schemas + thin handlers + argument validation | Deep domain logic |
| `src/design-research.mjs` | Deterministic Design Contract planning + curated research cards | Network ingestion or source full text |
| `src/motion-plan.mjs` | Motion plan contract with fact/recommendation attribution | Browser observation |
| `src/awards.mjs` | Awwwards parsing/ranking/blueprint/static motion + guarded fetch client | Persistence |
| `src/awards-index.mjs` | Local JSON corpus, atomic writes, lock, checkpoints, winners, watches | Awwwards HTML parsing |
| `src/browser-cdp.mjs` | Optional Chrome CDP capture/structure/motion | Required catalogue use |
| `src/icons.mjs` | Free icon fetch + 24h cache + credits | Other network paths |
| `src/version.mjs` | npm version check + hourly cache | Status rendering |
| `src/protocol.mjs` | JSON-RPC framing, MCP handshake, error codes, `textResult` | Business logic |
| `src/server.mjs` | Composition root, stdio loop, stderr banner | Tool behaviour |

## Build and tests

- `scripts/bundle.mjs` — deterministic assembler. `BUILD_ORDER` is the build
  manifest; missing or unlisted `src/*.mjs` modules fail the build. All sources
  are normalised to LF before concatenation, so CRLF and LF checkouts produce
  byte-identical output. `assertBundle` rejects leaked ESM statements and
  unresolved version placeholders.
- `scripts/build.mjs` — reads `package.json`, calls `bundleSource`, writes
  `dist/server.js` and `dist/cli.cjs`.
- `scripts/verify.mjs` — 47 live checks against the real catalogue, award
  validation and error paths. Network required.
- `test/*.test.mjs` — hermetic Node test files, one per domain. `npm test` runs
  `node --test ./test/*.test.mjs` (flat layout). Nested test folders require a
  test-command change first.
- `scripts/repro.mjs` — manual live probe for historical field issues. Not part
  of CI.

## Boundaries and known limitations

- **Free-only**: `isFreeRow`/`assertFreeRow` in `src/catalog.mjs` gate every
  retrieval path. Components/assets are free only when `premium === false`;
  skills/design systems have no premium concept.
- **Single-writer award index**: one lock file guards crawls. `wx` exclusive
  create closes the cross-process read-then-write race; stale takeover is
  best-effort (30-minute lease). Stale takeover remains a last-writer-wins
  window, documented in ADR-0003.
- **Browser optional**: catalogue and award search/inspect/blueprint/index work
  without Chrome. Capture/motion degrade with `BROWSER_UNAVAILABLE` and setup
  guidance.
- **Untrusted upstream data**: catalogue rows, Awwwards HTML, icons and docs are
  data. No instructions from fetched content are executed.
- **Inspo migration**: the five `aura_inspo_*` external workflow mappers were
  removed. Use catalogue searches, award/reference tools, `aura_diff`, and
  `aura_scaffold_page`; see `docs/v2/TOOL_CONTRACTS.md`.
- **Flat tests**: nested test folders are not discovered by the current
  `node --test ./test/*.test.mjs` command. Change the command in the same
  commit as any move.
